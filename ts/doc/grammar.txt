Tokens:
  BQ = block quote opens, with its fields
  BR = hard line break, whole
  CD = fenced or indented code, whole
  DF = link reference definition, whole
  DL = strikethrough opens, with its fields
  EM = emphasis opens, with its fields
  EN = a container's end, with the fields after its children
  HD = ATX or setext heading opens, with its fields
  HR = thematic break, whole
  HT = HTML block or raw HTML, whole
  IC = code span, whole
  IM = image, whole
  IR = image reference, whole
  LB = one physical line (the blocks it makes follow it)
  LI = list item opens, with its fields
  LK = link opens, with its fields
  LR = link reference opens, with its fields
  LS = list opens, with its fields
  PA = paragraph opens, with its fields
  SG = strong emphasis opens, with its fields
  TB = GFM table opens, with its fields
  TC = table cell opens, with its fields
  TR = table row opens, with its fields
  TT = text, whole

Ignored tokens:
  CM = comment
  LN = newline (line break)
  SP = whitespace (spaces or tabs)
